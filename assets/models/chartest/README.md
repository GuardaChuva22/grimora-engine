# Chartest

Character supplied by the user as `chartest.blend`, imported with Blender 5.2.
The body, material, bone lengths and native finger skin weights are preserved.
The import normalizes axes and units, gives bones the engine's semantic names, and
adds weapon/belt sockets. Index, grouped fingers and thumb keep their independent
native three-joint chains.

`tools/blender/hand_grip.py` measures the actual sword handle and fits the hand to it.
It aligns the socket across the knuckles, closes every phalanx and corrects only the
local distal finger skin needed to clear the handle. The right wrist receives a
small smooth hand/forearm weight blend so turning the hand does not split its seam.
The source .blend is not edited.
The generated `__grip_right` reference supplies the same grip to Mixamo, legacy clips
and the runtime pose baker. It is hidden in the animator. Measurements and local
surface correction limits are recorded in `right_hand_grip.json`.

`chartest.gltf` is the runtime asset. `chartest.blend` is the adapted, editable copy;
the original file is never saved over. The previous wanderer remains in its own folder.

Reimport from the repository root:

```powershell
& 'C:/Program Files/Blender Foundation/Blender 5.2/blender.exe' --background --python tools/blender/import_chartest.py -- --source '<path-to-original>/chartest.blend'
```

The legacy idle, walk, run, attack, hurt and death clips are retargeted from the
previous wanderer. The active **sword_idle** is an embedded animation retargeted
from Adobe Mixamo's **Breathing Idle**, using `tools/blender/mixamo_idle.py` and the
source FBX in `assets/animations/mixamo/`. Reimport automatically includes it when
that FBX exists. The rejected procedural idle is retained in `authoring_archive/`.

The active **sword_walk** is authored for this skeleton by
`tools/author_chartest_walk.py` (Python, NumPy and SciPy). It uses a one-second cycle
at **1.2 m/s**, double support, heel landing, toe push-off and opposite arm swing.
The foot heights are fitted to this mesh's actual sole vertices. The existing idle
supplies the arm/hand pose; this is not a correction of the grip or attack wrists.
The native **sword_run** is generated by the same script: a 2/3-second cycle at
**5.5 m/s**, with brief ground support, an airborne phase, heel recovery, bent
elbows and a mild forward lean. Both gaits retain the idle's relative wrist pose.
Their animation data is embedded in `chartest.gltf` and `chartest_walk.bin`;
it appears in **Só ver** in the animator. The old `sword_walk.ron` is preserved in
`authoring_archive/sword_walk.legacy.ron`. Reimport runs the walk authoring script
after export; run `python tools/author_chartest_walk.py` to regenerate just the walk.
The adapted `.blend` is the body/idle source; the walk is added to the glTF afterward.
The previous run is retained in `authoring_archive/sword_run.legacy.ron`.

The same authoring script now supplies native **jump**, **jump_fall** and
**jump_land** clips. The sandbox selects ascent/descent from vertical velocity,
holds the fall pose on long drops and starts landing only on physical ground
contact. The legs tuck during ascent and extend for contact; the arms move through
the arc. Landing flexes the knees and hips, with the chest, head and arms following
at slightly different times, then recovers over 0.40 s.
**jump_land_walk** and **jump_land_run** absorb the impact over the corresponding
gait so movement can continue with the feet matching horizontal speed. Stopping,
changing gait, attacking or jumping can interrupt the recovery.

The other editable sword animations live in `chartest_clips/*.ron` and are baked
against this character's skeleton on load. Reimport copies only missing RONs and
archives the procedural idle override so it cannot hide the Mixamo clip. Do not
restore a `sword_idle.ron` inside that folder unless deliberately replacing Mixamo.

The original file contains Sketchfab/FBX import node names but no source URL or
license metadata. Authorship/license information has not been inferred from those names.
