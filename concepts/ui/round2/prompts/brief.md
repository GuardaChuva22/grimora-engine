# Grimora UI concept, round 2: shared brief

Task: generate exactly ONE image with the built-in image generation tool (image_gen), at 1536x1024
landscape. Do not write code to draw it. Do not use HTML, SVG or scripts to produce the image.

After generating, copy the image from $CODEX_HOME/generated_images to the current directory under
the file name given in the direction file. Write nothing else, change nothing else, touch no other folder.
Finish by printing the saved file name.

The approved direction is MENU DE SONHO: real 1990s PlayStation RPG interfaces such as King's Field,
Vagrant Story and Shadow Tower. Translucent dark panels with a stepped dithered fade, hairline pale
borders, small caps pixel type, numbers shown plainly, unsettling minimalism, almost no ornament.

The attached images menu_sonho_hud.png and menu_sonho_inv.png are the approved style: match their
panels, line weights, typeface, palette and pixel scale exactly, so this looks like the same game.

Quality bar:
- It must look like a real screenshot of a shipped game: clean, restrained, generous spacing.
- Clear hierarchy, one alignment grid, panels that could be built from reusable pieces.
- Crisp low resolution pixel work with a limited palette. No smooth gradients, bevels or soft glows.
- All on-screen text is in Brazilian Portuguese, uppercase small caps, spelled exactly as written in the direction file.
- Never: gold filigree, floral marginalia, skulls, bones, stained glass, parchment, wood, cartoon style, glossy gems, logos, watermarks, crosses or other real religious symbols.
- If base_game.png is the backdrop, keep the world's art style, resolution and colours as in that image; do not repaint or pixelate it.
