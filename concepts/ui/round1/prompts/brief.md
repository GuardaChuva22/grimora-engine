# Grimora UI concept: shared brief

Task: generate exactly ONE image with the built-in image generation tool (image_gen), at 1536x1024
landscape. Do not write code to draw it. Do not use HTML, SVG or scripts to produce the image.

After generating, copy the image from $CODEX_HOME/generated_images to the current directory under
the file name given in the direction file. Write nothing else, change nothing else, touch no other folder.
Finish by printing the saved file name.

The game: Grimora, an open world dark fantasy RPG with a dreamlike, surreal PlayStation 1 look:
saturated ultramarine nights, oversized moons, emerald land, blood red dusks, crunchy textures,
monumental silhouettes. This image is a UI concept to choose an art direction.

Quality bar for every concept:
- It must look like a real screenshot of a shipped game, not a poster, not a website, not a mobile game.
- Clear hierarchy, consistent alignment, consistent grid, panels that could really be built from reusable pieces.
- Interface art is crisp low resolution pixel work, with a limited palette, as if drawn for a 640x360 screen and scaled up by an integer. No smooth gradients, glossy bevels, soft glows or modern vector look.
- All on-screen text is in Brazilian Portuguese, spelled exactly as written in the direction file, in a legible pixel typeface.
- Never: generic fantasy RPG look, World of Warcraft style, tan parchment scrolls, wood planks, cartoon style, glossy gems, stock sci-fi UI, logos, watermarks.
